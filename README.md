# 📝 BlogPur - A Django Blog with Authentication

BlogPur is a responsive blog web app built with Django. It supports user authentication, CRUD operations for blog posts, and a modern Bootstrap UI.

![Screenshot](prooduct.png)

## 🔥 Features

- ✅ User Sign Up / Login / Logout
- 📝 Create, Read, Update, Delete Posts
- 📸 Image Upload
- 🧑‍💻 Only authenticated users can post/edit/delete
- 🎨 Bootstrap 5 UI with Dark Mode

## 🚀 Tech Stack

- Python 3.11
- Django 4.x
- Bootstrap 5
- HTML/CSS
- SQLite (default)
